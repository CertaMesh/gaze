---
name: Monitor agents
scope: global
description: Check Solo workers and harvest results.
---

Use Solo MCP to monitor the agents or processes we have been discussing.

Use whoami first if you need to identify your project context. Check statuses and recent outputs. If workers are still active, do not busy loop or repeatedly poll them. Set a Solo wake timer or wake-when-idle timer so Solo can resume you when there is something to harvest. If a worker is blocked on a permission prompt, report or approve only if the request is clearly within scope. Do not interrupt active workers. Idle is not completion. On a terminal result, read the assigned existing status record, verify its evidence, record acceptance or blocker disposition and evidence links in the todo, archive the verified worker pad, then close the worker. A parent release may stay open; archiving a BLOCKED review does not complete its unresolved implementation. Preserve unharvested records. Reuse IDs and do not create separate brief/status/report/done pads. Summarize findings and suggest the next action.
