## TL;DR

- Scope is the current measurable subset only: 5 direct Kiji labels (`Email`, `IBAN`, `credit_card`, `phone`, `postal_code`) plus 2 partial proxies (`first_name`, `surname`) represented by the corpus `Name` span. This is not a 26-label benchmark.
- Headline metric is strict span leak rate: `1 - strict_recall`, where strict means byte-boundary exact match and canonical class exact match. F1 is intentionally not the ranker for this benchmark.
- Gaze rule-floor snapshot on commit `7348690` over 150 fixtures: `Email`, `credit_card`, German `phone`, global `phone`, and German/US `postal_code` have `0.000` strict leak rate; US `phone`, global `postal_code`, and `Name` proxy spans have `1.000` strict leak rate.
- `IBAN` is a scorer-label-map caveat in this snapshot: Gaze emits an equivalent bank-account/IBAN detection, but the current coverage oracle labels it `custom:iban`, so strict canonical class scoring records class mismatches and reports `1.000` strict leak rate until the benchmark label map is made explicit.
- Kiji direct-detector numbers were run locally with the pinned model artifact: macro strict recall is `0.125` for each locale (`0.875` strict leak rate). Observer-residual remains `not_run` pending a separate cleaned-output harness pass. The model identity is citable: `onnx-community/distilbert-NER-ONNX` at `3a19fe9404a4469d91aa3d551558a97f68872f67`, with canonical bundle checksum-file SHA256 `c129e135d86698e67c4836456212666f94a56ceaf995acd60532f557b3120d2f`.

## Methodology

Source methodology: Solo scratchpad 18, "Research synthesis - Kiji SafetyNet evaluation methodology".

The benchmark has two modes:

| Mode | Name | Input | Score meaning |
|---|---|---|---|
| 1 | Direct-detector | Raw coverage-loop fixture text passed directly to Kiji DistilBERT | Measures Kiji as a detector against the committed oracle |
| 2 | Observer-residual | Gaze rule pipeline first, then Kiji as Pass-3 SafetyNet observer over cleaned output | Measures residual leaks the rule floor missed and Kiji can still alert on |

Strict span recall counts a gold span as caught only when both byte boundaries and canonical class match exactly. Partial overlap is a miss in the headline metric and belongs in diagnostics. Class mismatch is also a miss because the manifest contract is typed.

F1 is rejected as the headline ranker. Gaze's Axis 1 asks "what leaked?", so false negatives dominate the safety claim. F1 can hide a high-leak class behind precision or easy classes and is therefore allowed only as a secondary convenience statistic.

The current coverage-loop corpus is synthetic and deterministic. The evaluated rule-floor command was:

```bash
cargo test -p gaze-recognizers --test coverage_loop -- --ignored --nocapture
```

## Composability Summary

Composability metrics are informational and apply after a Kiji run exists:

| Metric | Definition | Status |
|---|---|---|
| `agreement_with_rule_floor` | Kiji span and class exactly agree with a Gaze rule-floor span | `not_run` |
| `expansion_fraction` | Kiji span strictly expands an existing same-class rule-floor span | `not_run` |
| `contradiction_fraction` | Kiji overlaps a rule-floor span but maps to a different canonical class | `not_run` |
| `novel_tp_over_rule_floor` | Kiji catches a strict true positive not emitted by the rule floor | `not_run` |

Observer-residual mode should also report residual alert recall. That number is not an end-to-end masking improvement unless Kiji is moved from observer-only into a blocking path.

## Limitations

- This is not a 26-label Kiji benchmark. The current corpus measures 5 labels directly and 2 labels only through a coarse `Name` proxy; 19 Kiji labels are not measurable in this v0.8 document.
- The corpus has `de-DE`, `en-US`, and `global` buckets only. Locale claims must say German, not DACH.
- The `Name` proxy does not split first name from surname yet, so the two partial proxy labels share the same aggregate span support.
- The current strict scorer needs an explicit benchmark label map for semantically equivalent custom labels, most visibly `custom:iban`.
- No Kiji model artifact is pinned here. Publishing direct-detector or observer-residual Kiji numbers without SHA256 pins would violate the Axis 4 trust contract.
- This synthetic corpus is suitable for regression detection and bounded comparison. It is not a universal anonymization, legal compliance, or production-readiness claim.
