# v0.12 Locale-Basis Drain Scorecard

This report measures the mixed locale-basis change drained by PR #423. The
candidate introduces `LocaleBasis::{Document, Format}` and lets bundled
format-basis identifiers match independently of the document-language locale.
It is evidence only: no accepted baseline was installed or modified, and
`--accept-baseline` was not used.
