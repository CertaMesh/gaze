# v0.12 OpenPII External Baseline

**Run date:** 2026-07-10

**Gaze revision:** `ce77c84e8a3e0906fc5f4109fd8c146cad0a0919`

**Result:** the current pipeline materially improves on the deterministic floor,
but fails the Gaze zero-leak bar.

This is the first full external multilingual baseline for the current Gaze
pipeline. The run used only synthetic data and did not change production
detection behavior. The worktree was dirty because the benchmark harness was
being added; the tested recognizers and pipeline code matched the revision
above.

The strongest high-volume labels are email (91.84% byte recall), surname
(91.65%), city (90.85%), given name (90.78%), and street (90.27%). That shape
matches the current model contract: person, organization, and location labels
are mapped into Gaze, while its date label is explicitly dropped and most
structured identifiers are outside the model vocabulary.

The lowest language-level byte recall is Korean (30.38%), followed by Chinese
(36.58%), Japanese (41.62%), French (44.30%), and German (46.51%). The best
language slice reaches only 54.61%, so no language is close to the zero-leak
bar.

## Baseline decision

Any proposed replacement or additional NER model is evaluated against the same
reserved split. At minimum it must:

- exceed 48.44% all-PII byte recall and 37.67% full-entity coverage;
- exceed 59.97% direct-identifier byte recall and 49.11% direct full coverage;
- preserve or improve 92.36% byte precision and the 1.085% non-PII-byte FPR;
- report every regression by label and language, even when the aggregate rises;
- remain reversible by emitting ordinary manifest-backed Gaze substitutions;
- fail closed on model load and inference errors.

Those are comparison floors, not release targets. The project target remains
100% PII-byte recall and 100% zero-leak documents on every required holdout.
The next evaluation layer must add synthetic negative-only documents and
agentic-domain fixtures for JSON tool calls, streaming boundaries, OCR, and
tenant-specific identifiers.

The full aggregate result is generated locally at
`target/bench-data/openpii-micro/gaze-benchmark-full.json` and intentionally
remains untracked because it contains machine-specific run metadata.
