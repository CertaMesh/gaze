# v0.12 English/German Whole-Pipeline Baseline

**Run date:** 2026-07-10

**Gaze revision:** `fddd52dc474720d3833037c96ed0edfce26a2656`

**Result:** the current full pipeline fails all three hard correctness gates:
zero leak, exact restoration, and valid manifests.

This benchmark changed only the benchmark example, runner, and documentation;
it did not change production detection or policy behavior. The harness was
uncommitted during the measured run, while the production recognizers and
pipeline matched the revision above.

Pass 2 is the material safety improvement: it adds 52.11 percentage points of

No cell is close to the zero-leak contract. The full pipeline still exposes
41,820 annotated PII bytes and produces a fully protected document only 1.70%
of the time.

## SafetyNet flag and policy behavior

The full cell exercises the shipped flag path the benchmark previously
missed. Kiji scans the Pass 2 clean text; in `Resolve` mode its actionable
discoveries are tokenized into the session and returned manifest. Gaze then
rechecks the result and uses `Redact` fallback for conflicts or residual
suspects.

| SafetyNet policy signal | Current result |
| --- | ---: |
| Initial suspects | 17,628 |
| Initial actionable suspects | 17,458 |
| Initial class mismatches | 170 |
| Documents strict mode would reject | 1,280 / 1,886 (67.87%) |
| Documents with zero post-policy suspects | 1,519 / 1,886 (80.54%) |
| Residual post-policy suspects | 1,269 across 367 documents |

The flag is active, but the current behavior does not close the loop. The final
output can still contain SafetyNet suspects, and fallback redaction is not
reversible. Restore telemetry reports `success` on 1,882 documents even though
only 1,310 restore exactly, so telemetry success cannot currently substitute
for byte-exact verification.

The manifest audit also finds 2,071 out-of-bounds raw spans, 1,838
non-monotonic raw spans, and 9,994 raw-value mismatches. Code inspection matches
the measurement: the Resolve path creates promoted manifest entries from
post-Pass-2 clean coordinates, while the manifest contract expects original raw
coordinates. This baseline records the defect; it does not change production
behavior.

## English and German

Pass 2 behaves similarly across the two target languages. The generic Kiji
SafetyNet adds little recall but is especially over-broad on German.

| Language / cell | Byte recall | Byte precision | Non-PII-byte FPR | Full-entity recall |
| --- | ---: | ---: | ---: | ---: |
| English, Pass 2 | 65.75% | 81.02% | 3.43% | 63.00% |
| English, full Resolve | 67.98% | 77.43% | 4.41% | 63.54% |
| German, Pass 2 | 65.90% | 80.17% | 2.87% | 62.78% |
| German, full Resolve | 67.80% | 26.92% | 32.35% | 63.69% |

High-volume names, streets, cities, companies, and emails exceed 99% byte
recall in the full cell. Structured identifiers remain the dominant gap: age
is 0%; passport, ID-card, driver-license, birth-date, building number, national
ID, tax number, and SSN are all below 5% byte recall. The current name/location
models are therefore not a substitute for identifier-specific recognizers or a
PII-trained NER model.

## Baseline decision

Use this English/German test split as the primary before/after scorecard and
keep OpenPII as a secondary multilingual stress test. A proposed detector or
policy change cannot be promoted unless it:

- does not regress PII-byte recall, full-entity recall, or zero-leak documents;
- restores exactly on 100% of documents;
- produces valid manifests on 100% of documents;
- reports language and label regressions even if the aggregate improves;
- improves precision or documents an explicit, reviewed tradeoff;
- compares latency only after all correctness gates pass.

The immediate defect order is: repair reversible SafetyNet promotion and
fallback semantics, close residual post-policy suspects, then compare custom
NER candidates on the same frozen split. The current full cell is not a safe
release configuration under Gaze's north star.

A later warm OpenAI Privacy Filter diagnostic is documented separately in
[`v0.12-opf-daemon-sample.md`](v0.12-opf-daemon-sample.md). It materially raises
recall on a 50-row sample but does not pass availability, reversibility,
post-policy, or latency gates.
