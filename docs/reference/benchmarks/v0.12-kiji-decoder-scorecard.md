# v0.12 Kiji Decoder Scorecard

This report measures the Kiji label-registry and shared-decoder hardening in
PR #425. The candidate pins the reviewed nine-label classifier contract, routes
ORT, Tract, and Candle through one decoder, and rejects malformed outputs
before partial detections can escape. This is evidence only: no accepted
baseline was installed or modified, and `--accept-baseline` was not used.
