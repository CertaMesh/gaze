# Tutorials

Learning-oriented guides. A tutorial takes you end to end through a working result so you
learn how Gaze behaves by doing — not by looking things up. If you already know what you
want to accomplish, the [how-to guides](../how-to/index.md) are faster.

- **[Getting Started](getting-started.md)** — clean a document, store the restore key, send
  only safe text to an LLM, and restore the original values from the response. About ten
  minutes, end to end. Start here.

Once the round trip makes sense, branch out by task in the [how-to guides](../how-to/index.md),
look up exact behavior in the [reference](../reference/index.md), or read *why* the
guarantees hold in [explanation](../explanation/index.md).
