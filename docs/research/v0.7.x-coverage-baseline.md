## Commentary

Top uncovered buckets:

- `Name/de-DE`: 102 uncovered.
- `Name/en-US`: 84 uncovered.
- `Email/global`: 33 uncovered.
- `Email/de-DE`: 27 uncovered.
- `Email/en-US`: 22 uncovered.
- `custom:phone/en-US`: 82 uncovered.

Name misses dominate because several templates place names in prose cues that do
not satisfy current anchored-name constraints. This is useful signal for the
taxonomy epic: it shows where the rule floor is weakest before adding neural
oracle coverage.

Email misses are concentrated in structured contexts where punctuation, JSON
quoting, or newline placement changes boundaries. These should drive focused
regex and context-window tests before rulepack edits.

US national-phone misses are likely fixture-shape versus parser/regex
interaction. The generated values are synthetic NANPA 555-01xx forms, so fixes
must preserve the non-reachable fixture contract.

The three DE credit-card class mismatches are observed but not gated. They should
be handled as resolver/class-priority follow-up, separate from the uncovered
trend gate.

## Baseline Semantics

`baseline.json` stores this leak set. Blocking mode fails only when a current
bucket has more `Uncovered` labels than this baseline. Reducing uncovered counts
is always accepted; updating the baseline should be a conscious release-train
decision.
