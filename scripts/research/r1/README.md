# Reproduce the entity continuity experiment

This directory contains an isolated research prototype, no production wiring.
Findings are filed in Solo. The protocol is `protocol.json`; synthetic scenarios
are `scenarios.jsonl`, generated by `generate.py`. Python 3.11–3.13 is required
because the auxiliary own-corpus generator imports `tomllib`.

From the repository root:

```sh
python3.12 -m unittest discover -s scripts/research/r1 -p 'test_*.py'
python3.12 scripts/research/r1/generate.py
git diff --exit-code -- scripts/research/r1/scenarios.jsonl
CARGO_BUILD_JOBS=2 cargo build --offline -j 2 -p gaze-pii --no-default-features --example research_r1
python3.12 scripts/research/r1/run.py --split dev --output target/research/r1/dev.json
python3.12 scripts/research/r1/run.py --split test --output target/research/r1/test.json
```

The native example uses the production core and repeat sweep, with a synthetic
recognizer for explicit owner-known seed records, and a learned-evidence seed
ablation. It does **not** run the setup policy, bundled recognizers, NER, or a
safety-net model. Its privacy/continuity scores are mechanism evidence, not a
release score or shipped whole-stack recall. A small auxiliary slice uses the
unchanged repository layer R name generator with the same dev/test partitions;
its initial full name is explicitly supplied as an owner-known seed. No sealed
or downloaded per-document data is read. No release benchmark or timing runs.

Python alternatives use supplied owner records. `exact` is a deliberately
weaker ablation, not current Gaze. `normalized` allows case/whitespace plus full
address road spelling variants. `structured` adds name/address components and
abstains when ambiguous; `evidence` uses an independently trusted versioned
record context, and permits a one-edit full-name match only with that context.
`evidence_no_context` removes that context; `recent_first` resolves ambiguity
with record order as a recency surrogate; `fuzzy_unscoped` removes the fuzzy
context requirement; `scoped_parts` requires trusted context for every partial
reference. `canonical_restore` is an intentionally wrong negative control
that substitutes an entity's full value for an occurrence's source string.

Protection and linking are distinct: ambiguous known substrings can be
protected without choosing an entity. Source restoration uses an occurrence
map. The optional semantic root cannot replace that exact-byte map.

Utility is a deterministic field-routing capability test of five tasks per
conversation, using explicit owner-issued roots. It does not measure an LLM's
ability to select the right root or draft language. It cannot establish real
task-success gains. Permission tests exercise a local grant prototype, not an
implemented Gaze authorization extension. No model-generated label authorizes
disclosure. State size counts serialized fixtures/maps, not heap or RSS.

All evidence outputs go under ignored `target/`; the runner includes source,
binary, protocol and scenario hashes. It emits per-family and per-language
counts and records exact error denominators. These scripts are not part of
the public benchmark harness and do not change release scorecards.
